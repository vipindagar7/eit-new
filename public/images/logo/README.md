# Logo assets (TODO: add the official logo)

The navbar and footer look for these files, in this order:

- `eit-logo.svg` (or `.png` / `.webp`): full-colour logo, used on light backgrounds
- `eit-logo-white.svg` (or `.png` / `.webp`): white logo, used on the transparent navbar over the hero
  (if missing, `eit-logo.*` is shown in white automatically)

Until a logo exists a text wordmark is displayed.
